# Techstore

## Pagos

Variables requeridas en Render:

- `STRIPE_SECRET_KEY`: clave secreta de Stripe.
- `PAYPAL_CLIENT_ID`: Client ID de la aplicación PayPal.
- `PAYPAL_CLIENT_SECRET`: Client Secret de la aplicación PayPal.
- `PAYPAL_API_BASE_URL`: usa `https://api-m.sandbox.paypal.com` para pruebas sandbox.
- `API_URL`: URL pública del sitio, por ejemplo `https://tu-servicio.onrender.com`.

Render debe marcar `STRIPE_SECRET_KEY`, `PAYPAL_CLIENT_ID` y `PAYPAL_CLIENT_SECRET` como variables secretas.
